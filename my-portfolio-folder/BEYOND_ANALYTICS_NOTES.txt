How the button unlocks:
Visit Home / Projects / About / Contact, then return to the homepage. The button then stays for that browser session.
To test again from scratch, open the site in a new private window.

Edit a project: open index.html and search for "by-card".
Add a project: copy the commented template at the end of the project list.
Live links: Ayo Journey -> https://ayoolopon.netlify.app
            Oyinn's Treat -> https://oyinnstreat.netlify.app

(replace the existing files, keep the same folder names), commit, wait a minute, then hard-refresh.
